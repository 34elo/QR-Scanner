## 📌 О проекте

**ScanLog** — корпоративное Android-приложение для автоматизации складских операций на терминалах сбора данных (ТСД). Заменяет ручной учёт штрих-кодов: сотрудник сканирует товар физической кнопкой, приложение собирает коды, проверяет дубликаты и выгружает результат напрямую на Яндекс.Диск.

**Проблема, которую решает ScanLog:**
Сотрудники склада вручную записывали или фотографировали штрих-коды при приёмке и инвентаризации. Это медленно, ненадёжно и не даёт сразу сверить факт с планом.

**Решение:**
Три режима в одном приложении — сбор, проверка, настройка — плюс прямая выгрузка в облако без лишних шагов.

---

## 👥 Для кого

Приложение предназначено для **сотрудников склада и магазина**, работающих с терминалом сбора данных (ТСД) на базе Android со встроенным сканером ATOL.

## 🔧 Режимы работы

### 1. 📷 Сканирование

Основной рабочий режим.

| Функция | Описание |
|---|---|
| Сбор кодов | Нажатие физической кнопки сканера — код мгновенно добавляется в список |
| Счётчик | Количество отсканированных позиций отображается в верхней части экрана |
| Защита от дублей | Повторное сканирование того же кода блокируется с вибрацией (настраивается) |
| Сохранение | По завершении — сохранение в файл на устройстве или прямая выгрузка на Яндекс.Диск |

---

### 2. ✅ Проверка

Режим сверки факта с планом. Используется при **приёмке товара** и **инвентаризации**.

**Как работает:**
1. Загружается файл-эталон (CSV или XLSX) со списком ожидаемых кодов
2. Сотрудник сканирует физический товар
3. Приложение мгновенно показывает результат:
   - 🟢 **НАЙДЕН** — код присутствует в эталоне
   - 🔴 **НЕ НАЙДЕН** — код отсутствует в эталоне

---

### 3. ⚙️ Настройки

| Параметр | Описание | Пример |
|---|---|---|
| Префикс файла | Задаёт начало имени выгружаемого файла | `склад_А` → `склад_А_28.05.2025_14.30.csv` |
| Формат выгрузки | CSV или XLSX | — |
| Обрезка кода | Берёт только первые N символов штрих-кода | Убирает служебный суффикс |
| Дубликаты | Разрешить или блокировать повторное сканирование | — |

## 💾 Хранение и выгрузка

```
Устройство:    /Documents/QRScanner/
Яндекс.Диск:   /Scanner/
```

- Файлы сохраняются локально в папку `Documents/QRScanner` на устройстве
- При выгрузке на Яндекс.Диск файл передаётся **напрямую через API** — без создания промежуточных копий
- Поддерживаемые форматы: **CSV** и **XLSX**

## 🛠 Технологии

| Компонент | Технология |
|---|---|
| Платформа | Android (Java/Kotlin) |
| Сканер | ATOL SDK — подключение через `broadcast`-интерфейс, без использования камеры |
| Генерация XLSX | Apache POI |
| Сетевые запросы | OkHttp (фоновый поток) |
| Облачное хранилище | Яндекс.Диск REST API |

---

## 🔐 Архитектура и безопасность

- Токен Яндекс.Диска **не хранится в исходном коде** — передаётся на этапе сборки через `secrets.properties`
- Сканер подключается через системный `broadcast` от ATOL SDK — надёжный и быстрый способ без лишних разрешений на камеру
- Все сетевые операции выполняются в **фоновом потоке** — интерфейс не зависает

```
secrets.properties  ← не попадает в репозиторий (добавлен в .gitignore)
    └── YANDEX_DISK_TOKEN=xxxxx
```

## 🚀 Установка и запуск

### Требования

- Android 8.0 (API 26) и выше
- ТСД с аппаратным сканером ATOL
- Токен Яндекс.Диска (OAuth)

### Сборка

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/your-org/scanlog.git
   ```

2. Создать файл `secrets.properties` в корне проекта:
   ```properties
   YANDEX_DISK_TOKEN=ваш_токен_здесь
   ```

3. Собрать APK через Android Studio или командой:
   ```bash
   ./gradlew assembleRelease
   ```

4. Установить APK на ТСД и выдать необходимые разрешения (хранилище, вибрация)
